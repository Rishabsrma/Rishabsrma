## 🧠 About Me

I'm a backend engineer from Kathmandu who spends most of the day in AWS, NestJS, and the occasional React frontend. Over the last three years I've built SaaS platforms, IoT backends, and background-job systems that need to stay up and keep up.

A few things I care about:

- Serverless-first architecture on AWS — Lambda, DynamoDB, AppSync, and friends.
- Backends that don't fall over under load — queues (BullMQ + Redis), sensible caching, clean data models.
- Real-time IoT: getting device data into the cloud reliably with AWS IoT Core, MQTT, and WebSockets.
- Writing code I'll still understand six months from now.

I treat every day as a chance to pick up something new — a tool, a pattern, or a sharper way to break down a hard problem. Right now that curiosity is pointed at distributed systems and system design.

## 🐍 Contribution Snake

<div align="center">

<img src="https://raw.githubusercontent.com/Rishabsrma/Rishabsrma/output/github-contribution-grid-snake-dark.svg" alt="Contribution Snake" width="100%" />

</div>

> The snake feeds on my contribution graph — it's generated nightly by a GitHub Action. Setup steps are tucked below.

<details>
  <summary><b>⚙️ How to enable the Snake animation</b></summary>
  <br />

Create a workflow file at `.github/workflows/snake.yml`:

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: '0 0 * * *'
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - name: Generate snake
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>
